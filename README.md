# 📰 Fake News Detector (AI Project)

This project implements an AI-based Fake News Detection system using:

- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Logistic Regression
- LSTM Deep Learning Model

## Dataset
Fake and Real News Dataset (Kaggle)

## Accuracy
- Machine Learning Model: ~98%
- Deep Learning Model: ~97-99%

## Technologies Used
- Python
- Scikit-learn
- TensorFlow / Keras
- Google Colab
